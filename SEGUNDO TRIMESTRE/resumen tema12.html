Tema 12: Conversión y Adaptación de Documentos XML

XPath es un lenguaje que permite navegar, seleccionar y extraer información de documentos XML.

¿Qué es XPath?

XPath es un lenguaje utilizado para acceder a nodos dentro de documentos XML.

  • Permite localizar elementos
  • Extraer datos
  • Realizar cálculos
  • Visualizar información

Árbol XML

Un documento XML se organiza como un árbol con distintos tipos de nodos:

  • Nodo raíz (/)
  • Nodos elemento
  • Nodos atributo
  • Nodos de texto

Sintaxis XPath

Una expresión XPath se compone de:

  • Eje: Selección de elementos
  • Predicado: Condiciones (entre corchetes)
  • Selección: Resultado final

Ejemplo:

/concesionario/coche[@matricula="1234ABC"]/marca

Ejemplos XPath

  • Todos los coches: //coche
  • Coche número 2: //coche[2]
  • Matrículas: //coche/@matricula
  • Precio mayor a 20000: //coche[precio > 20000]

Lenguajes relacionados

  • XSLT: Transforma XML en HTML u otros formatos
  • XSL-FO: Genera documentos como PDF

Formatos de intercambio de datos

  • XML: Estructurado y jerárquico
  • JSON: Ligero y fácil de usar
  • CSV: Datos en tabla separados por comas
  • YAML: Basado en indentación, fácil de leer
