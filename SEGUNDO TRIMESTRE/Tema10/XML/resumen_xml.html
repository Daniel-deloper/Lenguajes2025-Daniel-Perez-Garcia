Resumen de XML

XML es un lenguaje de marcado diseñado para describir, estructurar y compartir datos entre distintos sistemas.

¿Qué es XML?

XML (Extensible Markup Language) es un lenguaje de marcado de propósito general definido por el W3C. Se utiliza para describir y compartir datos, no para mostrarlos.

  • Similar a HTML, pero no predefinido
  • Las etiquetas las define el programador
  • Muy usado en intercambio de información

Características de XML

  • Lenguaje de estructura libre
  • Formato jerárquico en forma de árbol
  • Un único elemento raíz
  • Distingue mayúsculas y minúsculas
  • Los documentos pueden validarse

Estructura de un Documento XML

  • Prólogo: declaración XML, hojas de estilo y validación
  • Cuerpo: elemento raíz y resto de elementos
  • Uso opcional de espacios de nombres (namespace)

Documento Bien Formado

Un documento XML bien formado cumple las reglas sintácticas del estándar XML.

  • Todas las etiquetas deben cerrarse
  • Los atributos van entre comillas
  • Un solo elemento raíz
  • Respeta mayúsculas y minúsculas

Validación XML

Validar un XML consiste en comprobar que cumple una estructura definida.

  • DTD: define elementos y atributos
  • XSD: define tipos de datos y restricciones más precisas

Un XML puede estar bien formado pero no validado.

Namespace en XML

El espacio de nombres evita conflictos cuando se combinan elementos de distintos orígenes.

  • Se declara con (xmlns)
  • No tiene que ser una URL real
  • Identifica de dónde viene cada elemento

Parser XML

Un parser es el programa que lee un archivo XML y lo convierte en una estructura que puede procesar el ordenador.

  • Detecta errores de sintaxis
  • Permite trabajar con los datos
  • Ejemplos: navegador web, Visual Studio Code
