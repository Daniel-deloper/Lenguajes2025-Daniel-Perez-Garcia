Propiedad overflow

La propiedad overflow controla qué pasa cuando el contenido se sale del tamaño asignado a un contenedor.

Ejemplos visuales:

overflow: visible

Este texto es muy largo y sobrepasa la caja… por eso se sigue viendo fuera del contenedor.

overflow: hidden

Este texto también es muy largo, pero se corta y no se muestra la parte sobrante.

overflow: scroll

Este texto es muy largo, así que aparece una barra de desplazamiento para leerlo.
